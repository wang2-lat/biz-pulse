# biz-pulse

Lightweight CLI tool for small business to track customers, deals, and team tasks.

## Features

- **Customer Management**: Add customers, update sales stages, track status
- **Deal Pipeline**: Manage deals, mark as won/lost, track revenue
- **Business Stats**: Monthly wins, at-risk customers, sales funnel visualization
- **Meeting Records**: Log meeting notes and outcomes
- **Task Tracking**: Assign tasks, track completion status
